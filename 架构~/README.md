## 总体架构速览

```
┌─────────────────────────────────────────────────────────────────┐
│                      Level (关卡层)                               │
│  ┌─────────────────────────┐   ┌─────────────────────────────┐  │
│  │    ViewModule (视图层)    │◄─►│   LogicModule (逻辑层)       │  │
│  │   V1-V5                 │   │   L1-L10                    │  │
│  └─────────────────────────┘   └─────────────────────────────┘  │
└───────────────────────────┬─┬────────────────────────────────────┘
                            │ │  双向通信
┌───────────────────────────┼─┼────────────────────────────────────┐
│               CapabilityModule (通用能力层)                        │
│  C1-C21: 序列化/调试/本地化/资源/日志/网络/事件/存储/流程/       │
│  对象池/音频/过场/UI/输入/脚本/物理/摄像机/安全/场景/天气/性能   │
└───────────────────────────┬──────────────────────────────────────┘
                            │  单向依赖
┌───────────────────────────┼──────────────────────────────────────┐
│                   DriverLayer (驱动层)                             │
│  D1: GameWorld | D2: 基础类库 | D3: Debug | D4: 平台抽象层        │
└──────────────────────────────────────────────────────────────────┘
```
