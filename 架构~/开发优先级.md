### 14. L7 — 战斗数值体系

- **状态**：📋 规划完成，待实现
- **设计核心**：
  - **GameplayTag（L0）**已独立为 Level 层共享基础设施，不绑定战斗系统
  - **AttributeSet<TId>** — 泛型属性集合，`TId` 解耦 Entity（可选依赖）
  - **Modifier** — 可扩展运算类型（Add/Multiply/Override/MinCap/MaxCap）+ 优先级控制计算顺序
  - **DamagePipeline** — 四阶段伤害管线（PreMigration → DamageCalculate → PostMigration → ApplyDamage），核心公式可被项目整体替换
  - **BuffSystem** — 层叠规则驱动（Single/Multi/Refresh/Extend）+ 生命周期回调
  - **IAbilitySystem** — 技能激活预检（GameplayTag 条件）+ 效果管道触发
- **数据层**：统一使用 Luban + L4 Sheet 系统（含 AssetRef\<T\> 处理 Unity 资源引用），不引入 ScriptableObject
- **依赖**：L0 GameplayTag（可选）、C7 EventBus（可选）；Entity 通过 `TId` 泛型可选
- **不依赖**：~~L1 MVC~~、~~L2 HFSM~~、~~L3 Entity~~
- **子模块可选性**：Attribute（独立）→ Effect（依赖 Attribute）→ Buff（依赖 Effect）→ Ability（依赖 Buff + GameplayTag），项目可按需取用
- **工作量**：大
- **建议**：RPG/动作/卡牌/MOBA 战斗刚需。分阶段：Attribute + DamagePipeline → Buff 系统 → Ability 技能系统。

- **方案**：**自编译 FixedMathSharp.dll（.NET Standard 2.1）+ precompiledReferences 引用 + Core 层自定义 MemoryPack 格式化器**
- **实现方式**：
  - `HN.Framework.Core.Vendor.FixedMathSharp.asmdef` 通过 `precompiledReferences: ["FixedMathSharp.dll"]` 引入预编译 DLL
  - `FixedMathSharpFormatters.cs` 在 `Capability/Serialization/` 下，提供 8 个 `MemoryPackFormatter<T>`（Fixed64、Vector2d/3d/4d、FixedQuaternion、Fixed4x4、FixedBoundBox、FixedBoundSphere）
  - `FormattersInitializer.RegisterAll()` 批量注册所有格式化器
  - `HNFixedPoint.cs` 通过 `using HNFixedPoint = FixedMathSharp.Fixed64;` 提供类型别名兼容
- **测试**：`FixedMathSharpFormattersTests.cs`（序列化往返测试，17 个用例全部通过）
- **工作量**：中（自编译 DLL + 8 个自定义格式化器，~400 行）
- **必要性**：❌ **非必须**。仅 lockstep 帧同步场景需要（RTS、格斗、竞速等），默认状态同步（FishNet SyncVar/SyncList/Prediction）使用 `float` 无需定点数
