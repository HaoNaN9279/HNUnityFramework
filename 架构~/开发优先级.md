  1. 从 `mrdav30/FixedMathSharp` 仓库取 `src/FixedMathSharp/` 源码（.NET 核心库，非 Unity 包装）
  2. 放入 `Runtime/HN.Framework.Core/Vendor/FixedMathSharp/`
  3. 新建 `HN.Framework.Core.Vendor.FixedMathSharp.asmdef`（`noEngineReferences: true`）
  4. 机械剥离 `[MemoryPackable]` / `[MemoryPackInclude]` 属性和 `using MemoryPack;`（~15 个文件）

  6. 注册到 Core 层 `MemoryPackFormatterProvider`
- **工作量**：中（源码纳入 + 去属性 ~15 个文件 + ~10 个自定义格式化器，合计 ~400 行）
