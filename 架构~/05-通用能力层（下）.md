
## C12 — 过场动画系统

- **状态**：✅ 已实现（Phase 1~4 全部完成）
- **依赖**：`com.unity.timeline`（**强制依赖**）
- **设计原则**：基于 Unity Timeline 构建，不自建序列化引擎。核心创新是 `CutsceneBindingResolver`（自定义 `IExposedPropertyTable`），通过角色名而非具体 GameObject 引用进行 Track 绑定，实现 TimelineAsset 与场景解耦。自动协调输入阻塞（C14）、摄像机接管（C17）、UI 控制（C13）。
- **命名空间（Core）**：`HN.Framework.Core.Capability.Cutscene`
- **命名空间（Unity）**：`HN.Framework.Unity.Capability.Cutscene`

Core 层（12 个文件）：
```
ICutsceneManager — 全局管理器：Play/Enqueue/StopAll/PauseAll/ResumeAll，支持优先级和跳过模式
ICutscenePlayer — 单次过场会话句柄：Play/Pause/Resume/Stop/Skip/SeekTo，事件回调（OnFinished/OnStateChanged）
CutsceneAssetRef — 过场资源引用（Addressables key + 默认角色绑定映射）
CutsceneBindingMap — 角色名 → 绑定目标映射（MemoryPack 可序列化，支持 EntityId/ScenePath/Tag/ActorComponent 四种解析方式）
CutsceneRole — 角色槽位数据
CutsceneState / CutscenePriority / CutsceneSkipMode / CutsceneEvent — 状态枚举、优先级、跳过策略、事件数据结构体
CutsceneGlobalSettings — 全局配置（GlobalSkipEnabled/GlobalSpeedMultiplier）
ICutsceneSubtitle — 字幕数据模型（StartTime/EndTime/LocalizationKey/SpeakerRole）
```

Unity 层（12+ 个文件）：
```
CutsceneManager — ICutsceneManager 实现。内部维护活跃播放列表 + 排队队列，按优先级仲裁：
  Critical(立即停所有) > Important(暂停低优先级) > Normal(排队) > Background(空闲时播放)
CutscenePlayer — PlayableDirector 包装器。资源加载→PlayableGraph 构建→播放→释放：
  · 内部复用 Director GameObject 对象池
  · 自动注册完成/跳过/中断回调
  · 播放/停止时自动推送/弹出 IInputBlocker、切换 ICameraManager、隐藏/恢复 UI
CutsceneBindingResolver — 自定义 IExposedPropertyTable。运行时将 Track binding name 按 CutsceneBindingMap 解析为目标 GameObject
CutsceneActor — 标记组件，标识 GameObject 可作为过场演员
CutsceneInputBlock — 过场输入阻塞器（IInputBlocker 集成）
CutsceneCameraHook — 过场摄像机接管（ICameraManager 集成）
CutsceneSubtitleDisplay — 字幕显示组件（C3 本地化集成）
自定义 Timeline Track（5 种）：
  SubtitleTrack/SubtitleClip — 字幕轨，自动读取本地化字符串
  DialogueTrack/DialogueClip — 对话触发轨，对接游戏对话系统
  GameStateTrack/GameStateClip — 游戏状态变更轨（设置 Animator 参数、启用/禁用组件）
  ShakeTrack/ShakeClip — 屏幕震动轨（调用 ICameraManager.Shake）
  TimelineEventTrack/TimelineEventClip — 通用事件轨（向 C7 EventBus 发布事件）
```

Editor：
```
CutsceneEditorWindow — 过场编辑器窗口，预览 + 角色分配 + 演员映射
CutsceneBindingInspector — 角色绑定 Inspector，可视化编辑 CutsceneBindingMap
CutscenePreviewTool — 预览工具
```

跨模块协调：
| 阶段 | 输入(C14) | 摄像机(C17) | UI(C13) |
| Playing | Push InputBlocker | 切换到过场摄像机 | 显示黑边 + 字幕面板 |
| Finished | Pop InputBlocker | 恢复过场前摄像机 | 隐藏黑边 + 字幕面板 |

依赖关系：C4 AssetManager（Addressables 加载 TimelineAsset）→ C7 EventBus（TimelineEventTrack）→ C3 Localization（字幕）→ C14 Input（输入阻塞）→ C17 Camera（摄像机接管）→ 可选 C13 UI（黑边/字幕面板）/ 可选 L3 Entity（EntityId 绑定模式）。

**Phase 1~4 已全部实现（2026-07-17）：**
- **Core 层（11 个文件）**：CutsceneState.cs、CutscenePriority.cs、CutsceneSkipMode.cs、CutsceneEvent.cs、CutsceneGlobalSettings.cs、ICutscenePlayer.cs、ICutsceneManager.cs、CutsceneAssetRef.cs、CutsceneBindingMap.cs、CutsceneRole.cs、ICutsceneSubtitle.cs → 均编译于 `HN.Framework.Core`
- **Unity 层（18 个文件）**：CutsceneBindingResolver.cs、CutsceneActor.cs、CutscenePlayer.cs、CutsceneManager.cs、CutsceneCameraHook.cs、CutsceneSubtitleDisplay.cs、CutsceneCanvas.cs + Tracks/ (SubtitleTrack/Clip/Behaviour、DialogueTrack/Clip/Behaviour/DialogueTriggerEvent、TimelineEventTrack/Clip/Behaviour、ShakeTrack/Clip/Behaviour、GameStateTrack/Clip/Behaviour) → 均编译于 `HN.Framework.Unity`
- **Editor 层（2 个文件）**：CutsceneBindingInspector.cs、CutsceneEditorWindow.cs → 编译于 `HN.Framework.Editor`
- **测试（9 个文件）**：Core 层 4 个（39 用例通过）、Unity 层 5 个（37 用例通过）

## C14 — 输入系统

- **状态**：✅ 已实现
- **命名空间（Core）**：`HN.Framework.Core.Capability.Input`
- **命名空间（Unity）**：`HN.Framework.Unity.Capability.Input`

**设计哲学**：基于 Unity Input System Package 的框架级封装，提供输入映射、多设备适配、输入优先级与屏蔽机制。

Core 层（5 个文件）：
```
IInputManager      接口：RegisterAction / UnregisterAction / EnableActionMap / DisableActionMap / Blocker
IInputBlocker      接口：Push(token, priority) / Pop(token) / IsBlocked(actionPriority)
InputAction        数据模型（IReference）：ActionName / ActionType / DefaultBinding
InputContext       只读结构体：ActionName / Phase(Started/Performed/Canceled) / Value
InputTypes         枚举：InputActionType(Button/Value/Vector2), InputPhase
```

Unity 层（5 个文件）：
```
InputManager            封装 UnityEngine.InputSystem，实现 IInputManager + IDisposable
InputBlocker            内部类，基于 Dictionary<object,int> 优先级栈
DeviceDetector          自动检测活跃输入设备，触发 OnControlSchemeChanged
TouchInputAdapter       创建 OnScreenStick / OnScreenButton 虚拟控件
InputActionAssetLoader  静态工具类：LoadFromJson / LoadFromAsset / UnloadAsset
```

Editor：
```
InputDebugger — 运行时输入可视化面板 ✅ 已实现
```
