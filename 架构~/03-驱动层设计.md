## D1 — GameWorld

- **状态**：✅ 已实现
- **命名空间**：`HN.Framework.Core.Driver`
- **定位**：框架全局驱动根节点，纯 C# 类，无 MonoBehaviour 依赖
- **持有（内置创建，永远非空）**：PoolManager, ProcedureManager, ControllerManager, DebugHub, EntityManager, EventBus, AISystem, GameplayTagManager
- **注入（非空，由 GameWorldDriver 保证注入）**：ILogProvider
- **注入（可空，项目可按需替换或置空）**：IAssetManager?, INetworkManager?, IStorageProvider?, IFrameSyncManager?, IInputManager?, IUIManager?, ILocaleProvider?, IPhysicsWorld?, ICameraManager?, ICutsceneManager?, ITickable? QuestManager（由 GameWorldDriver 或项目代码注入）
- **为空策略**：GameWorld 只保证构造函数创建的模块非空；所有外部注入模块默认可空，最大化适配不同项目类型
- **驱动**：`Tick()` → `LateTick()`，按固定顺序驱动所有模块

## D2 — 基础类库

### D2.1 ITickable / IReference

- **状态**：✅ 已实现
- **接口**：`ITickable`（Tick + LateTick），`IReference`（Clear，用于 ReferencePool 回收）
- **说明**：框架内所有需要帧更新的模块实现 ITickable，所有池化对象实现 IReference

### D2.2 HNLogicTime

- **状态**：✅ 已实现
- **命名空间**：`HN.Framework.Core.Driver.Common`
- **类型**：静态纯数据类
- **属性**：`Time`, `DeltaTime`, `LogicFrameCount`（三个静态属性）
- **保留静态的理由**：纯数据类，不依赖任何外部服务，不持有任何业务状态

### D2.3 ReferencePool

- **状态**：✅ 已实现
- **命名空间**：`HN.Framework.Core.Driver.Common.Pool.ReferencePool`
- **类型**：静态工具类，线程安全
- **功能**：`Acquire<T>()` / `Release(T)` 零 GC 对象复用，基于 `IReference` 接口
- **附带**：8 种可池化集合 + 4 种并发集合（PooledList, PooledDictionary, PooledQueue 等）
- **保留静态的理由**：类比 .NET 的 `ArrayPool<T>.Shared`，无状态，无生命周期管理需求

### D2.4 MemoryPack Serialization Core

- **状态**：✅ 已实现
- **命名空间**：`HN.Framework.Core.Driver.Common.Serialization`
- **定位**：高性能二进制序列化基础设施
- **组成**：
  - `MemoryPackSerializer` 包装器：统一序列化/反序列化入口
  - `ISerializer` 接口：统一序列化/反序列化 API
  - `MemoryPackFormatterProvider`：格式化器注册提供器
- **集成**：使用 MemoryPack v1.21.4（vendored source，独立 asmdef），Core 层可序列化类型使用 `[MemoryPackable]` 属性
- **被使用方**：C6 Network（消息序列化）、C8 Storage（存档序列化）、L4 Sheet（二进制配置加载）、C2 Debug（结构化日志导出）

### D2.5 HNRandom

- **状态**：✅ 已实现
- **命名空间**：`HN.Framework.Core.Driver.Common.Math`
- **定位**：确定性伪随机数生成器，基于 xorshift128+ 算法，支持种子设置和状态序列化
- **必要性**：✅ **核心 D2，推荐保留**。`System.Random` 跨 .NET 版本/平台不保证一致性，框架提供确定性 PRNG 对回放、测试、多人同步随机数有独立价值
- **实现量**：小（~213 行纯 C#，无依赖）

### D2.6 FixedMathSharp ⚠️ 可选模块（第三方定点数库）

- **状态**：✅ 已引入（Core/Vendor FixedMathSharp.dll，可选，仅 lockstep 需要）
- **定位**：第三方定点数数学库（Q32.32），引入 [FixedMathSharp (Lean)](https://github.com/mrdav30/FixedMathSharp) 替代自研 `HNFixedPoint`
- **必要性**：❌ **非必须，降级为可选**。框架默认状态同步（FishNet SyncVar/SyncList/Prediction）使用 `float`，无需定点数。仅 RTS、格斗游戏等 lockstep 场景才需要
- **方案**：Core/Vendor 纳入 Lean 编译 DLL + Core 层自定义 MemoryPack 格式化器
  - `HN.Framework.Core.Vendor.FixedMathSharp.asmdef`（`noEngineReferences: true`）
  - 在 `HN.Framework.Core.Capability.Serialization` 下编写 `FixedMathSharpFormatters.cs`，为需要序列化的定点数类型实现 `MemoryPackFormatter<T>`
  - 注册到 `MemoryPackFormatterProvider`，由 Core 层 `ISerializer` 统一入口
- **需要自定义格式化器的类型**：`Fixed64`, `Vector2d`, `Vector3d`, `Vector4d`, `FixedQuaternion`, `Fixed4x4`, `FixedBoundBox`, `FixedBoundSphere`（按需增量添加）
- **HNFixedPoint.cs** 保留为 `HN.Framework.Core.Driver.Common.Math` 下的类型别名

## D3 — Debug 基础设施

- **状态**：✅ 已实现（数据模型 + Capability 运行时 + Unity RuntimeDebugConsole）
- **命名空间**：`HN.Framework.Core.Driver.Common.Debug`

**数据模型：**

```csharp
// 日志等级
public enum LogLevel { Debug, Info, Warning, Error, Fatal }

// 模块级日志通道
public interface ILogChannel
{
    string Name { get; }       // e.g. "pool", "network", "audio"
    bool Enabled { get; set; } // 运行时开关
}

// 结构化日志条目
public readonly struct LogEntry
{
    public DateTime Timestamp { get; }
    public string Channel { get; }
    public LogLevel Level { get; }
    public string Message { get; }
    public object Context { get; } // 可选结构化上下文
}

// 调试命令
public interface IDebugCommand
{
    string Name { get; }        // e.g. "pool.show"
    string Description { get; } // e.g. "显示对象池统计面板"
    void Execute(string[] args);
}

// 调试中枢
public interface IDebugHub
{
    void RegisterChannel(ILogChannel channel);
    void RegisterCommand(IDebugCommand command);
    void Log(LogLevel level, string channel, string message, object context = null);
}
```

### D4.2 资源操作器（AssetManager + Operators）

- **状态**：✅ 已实现
- **核心接口**：`IAssetManager` 定义于 Core（`HN.Framework.Core.Capability`），负责资源组加载、引用计数、自动卸载
- **实现**：`AssetManager` 在 Unity 程序集中，实现 `ITickable` + `IAssetManager`
  - 内部使用 `IAssetOperator` 接口委托底层加载
  - 维护弱引用缓存（AssetCacheItem），支持引用计数自动卸载
- **三种底层操作器**：

| 操作器 | 程序集 | 使用场景 |
|--------|--------|----------|
| `AddressablesOperator` | Unity | 运行时主要路径 |
| `AssetDatabaseOperator` | Unity（`#if UNITY_EDITOR`） | 编辑器快速迭代 |
| `ResourcesOperator` | Unity | ⚠️ deprecated，保留 `[Obsolete]` |

- **GameWorldDriver 注入模式**：
```csharp
var assetManager = new AssetManager();
#if UNITY_EDITOR
    assetManager.SetOperator(new AssetDatabaseOperator());
#else
    assetManager.SetOperator(new AddressablesOperator());
#endif
World.AssetManager = assetManager;
```

### D4.6 模块级配置架构（Settings 扩展体系）

框架采用 **去中心化、模块自包含** 的配置架构：每个模块定义自己的配置 `ScriptableObject` ，与模块运行时代码**同目录放置**，通过 `HNModuleSettingsUtility` 统一管理创建/加载，通过 `[SettingsProvider]` 自动发现注册到 Project Settings。

**设计原则：**

- **Module co-location**：配置 SO 定义放在模块 Runtime 代码所在目录，配置 Editor 面板放在模块 Editor 代码所在目录
- **零注册中心**：无需手动注册模块到某个中心列表，Unity `[SettingsProvider]` 属性自动发现
- **惰性创建**：`GetOrCreateSettings<T>()` 只在首次访问时创建 .asset 文件
- **Editor-only**：`GetOrCreateSettings`/`GetSerializedSettings` 包裹在 `#if UNITY_EDITOR` 中，Runtime 只读配置值

**代码模式：**

```csharp
// Runtime/Capability/MyModule/Settings/MyModuleSettings.cs
[CreateAssetMenu(...)]
public class MyModuleSettings : ScriptableObject
{
    public string SomeProperty;
#if UNITY_EDITOR
    public static MyModuleSettings GetOrCreateSettings()
    {
        return HNModuleSettingsUtility.GetOrCreateSettings<MyModuleSettings>(AssetPath);
    }
    public static SerializedObject GetSerializedSettings()
    {
        return HNModuleSettingsUtility.GetSerializedSettings<MyModuleSettings>(AssetPath);
    }
#endif
    public static readonly string AssetPath = "Assets/Project/RuntimeAssets/MyModule/MyModuleSettings.asset";
}

// Editor/MyModule/Settings/MyModuleSettingsProvider.cs
public static class MyModuleSettingsProvider
{
    [SettingsProvider]
    public static SettingsProvider CreateSettingsProvider()
    {
        return new SettingsProvider("Project/HN Unity Framework/MyModule", SettingsScope.Project)
        {
            label = "MyModule",
            guiHandler = (searchContext) =>
            {
                var settings = MyModuleSettings.GetSerializedSettings();
                // 使用 SerializedProperty 绘制
            }
        };
    }
}
```

| `LocalizationSettings` | `Runtime/.../Capability/Localization/Settings/` | `Editor/Localization/Settings/` | Project/HN Unity Framework/Localization |
| `BuildPipelineSettings` | — (纯 Editor) | `Editor/BuildPipeline/Settings/` | Project/HN Unity Framework/Build Pipeline |
