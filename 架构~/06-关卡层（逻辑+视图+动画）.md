## 九、关卡逻辑层

### L1 — MVC 框架

- **状态**：✅ 已实现
- **命名空间**：`HN.Framework.Core.Level.Logic`

**架构澄清：**

| 角色 | 定位 | 所在层 | 说明 |
|------|------|--------|------|
| **M (Model)** | 数据 + 业务逻辑 + 存储 | LogicModule (Core) | `Model<T>` 抽象类管理 `ModelUnit` 列表；`IReadOnlyModel<T>` 提供只读访问 + 变化通知 |
| **V (View)** | 显示逻辑 + 交互反馈 | ViewModule (Unity) | `ViewBase` 绑定并控制 `UnityEngine.GameObject`；由 Controller 驱动刷新；可通过 `IModelObserver` 订阅 Model 变化 |
| **C (Controller)** | 协调 M 和 V，处理用户输入 | LogicModule (Core) | `Controller` 抽象类管理 `ControllerUnit` 列表；注册于 `ControllerManager`；通过 V 接收输入，驱动 M 更新 |

**已有类型清单：**

```
Controller          — 抽象基类，持有 PooledList<ControllerUnit>，实现 ITickable + IReference
IController         — Controller 接口
ControllerUnit      — Controller 的逻辑单元
IControllerUnit     — ControllerUnit 接口
ControllerManager   — 注册/注销/Initialize/Tick/LateTick
Model               — 抽象基类，持有 PooledList<ModelUnit>
IModel              — Model 接口
ModelUnit           — Model 的逻辑单元
IReadOnlyModel<T>   — Value 属性 + OnValueChanged 事件
ReadOnlyModel<T>    — 默认实现（sealed class），SetValue() 仅在值变化时触发事件
```

**ControllerManager 生命周期：**
1. `RegisterController(controller)` — 注册到内部列表
2. `Initialize()` — 遍历所有 Controller，调用其 Initialize()
3. `Tick()` / `LateTick()` — 每帧遍历并驱动所有 Controller
4. Controller.Initialize() → 遍历所有 ControllerUnit，调用 Initialize()；然后 OnInitialize() 虚方法 → OnFirstFrame()

### L0 — GameplayTag（层级标签系统）

### L7 — 战斗数值体系（属性 / 效果 / Buff / 技能）

- **状态**：✅ 已实现
- **命名空间**：`HN.Framework.Core.Level.Logic.Combat`

基于 GAS 模式的数值组件体系。**核心四子模块（Attribute / Effect / Buff / Ability）全部实现，含完整 EditMode 单元测试**。**子模块可独立拆用**，适配不同游戏类型。**天然可插拔**（Level 层上层模块，无反向依赖，GameWorld 不持有其接口）。

**子模块依赖链：**

```
Attribute(独立) → Effect(依赖 Attribute) → Buff(依赖 Effect) → Ability(依赖 Buff + L0 GameplayTag)
                                                                          ↑ C7 EventBus(可选)
```

**不同游戏类型的子模块选择：**

| 类型 | GameplayTag | Attribute | Effect | Buff | Ability |
|-----|:-----------:|:---------:|:------:|:----:|:-------:|
| 休闲/叙事 | ✅可选 | ❌ | ❌ | ❌ | ❌ |
| RPG/MOBA/卡牌 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 放置/数值养成 | ❌ | ✅ | ✅简化 | ❌ | ❌ |
| 平台跳跃(简化) | ❌ | ✅仅HP | ❌ | ❌ | ❌ |

**Attribute 子系统：**

```csharp
public class AttributeSet<TId>   // TId 泛化解耦 Entity：用 EntityId 需 Entity，用 int/string 不需要
{
    float GetBaseValue/FinalValue(AttributeType);
    ModifierHandle AddModifier(Modifier<TId>);  // ModOp: Add|Multiply|Override|MinCap|MaxCap
    void RemoveModifier(ModifierHandle);         // Priority 控制计算顺序
    event Action<AttributeType,float,float> OnValueChanged;
}
// 默认计算顺序：Override → Add(按Priority) → Multiply(按Priority) → MinCap → MaxCap
```

**DamagePipeline（四阶段伤害管线，核心公式可替换）：**

```
PreMigration(增伤/减伤判断) → DamageCalculate(默认加减法公式,可替换) 
  → PostMigration(护甲/分摊/反弹) → ApplyDamage(应用到目标)
```

**Effect / Buff / Ability 核心接口：**

```
IEffectPipeline:  Apply(EffectSpec) → ApplyResult        // Instant|Duration|Infinite
BuffSystem:        ApplyBuff/RemoveBuff/Tick              // 层叠: Single|Multi|Refresh|Extend
IAbilitySystem:    TryActivateAbility/ApplyEffect/RemoveEffect  // 标签条件预检 CanActivate
```

**数据层：** 所有数据定义统一走 Luban + L4 Sheet，**不引入 ScriptableObject**。Unity 资源引用通过 `AssetRef<T>` 存 Addressables label 字符串，运行时异步加载：

```
Excel(tb_attribute/tb_ability/...) → Luban → C# struct(MemoryPackable) + .bin → L4 SheetManager
  → 运行时 world.SheetManager.GetTable<int,AbilityDefine>("tb_ability").Get(1001)
  → Unity 资源: AssetRef<T>.LoadAssetAsync() via Addressables
```

**依赖：** L0 GameplayTag（可选）+ C7 EventBus（可选）；**不依赖** ~~L1 MVC~~、~~L2 HFSM~~、~~L3 Entity~~（Entity 通过 `TId` 泛型可选）

### V1 — UI 系统运行时

- **状态**：✅ Phase 2 已完成

- **对应能力接口**：C13 的 `IUIManager`

**7 层 Canvas 栈：**

| 层 | SortOrder | 说明 |
|----|:---------:|------|
| Background | 0 | 场景背景层 |
| Scene | 100 | 3D 场景 UI（HUD、血条） |
| UI | 200 | 主界面（HUD、菜单） |
| Popup | 300 | 弹窗、对话框 |
| Toast | 400 | 自动消失提示 |
| Guide | 500 | 新手引导覆盖层 |
| System | 600 | 系统级覆盖（加载画面、错误提示） |

**栈导航：**
- `Push(type)` / `Pop()` — 入栈/出栈，支持返回键处理
- `Show(type)` / `Hide(type)` — 不改变栈的显示/隐藏
- `PushAsync(path)` / `ShowAsync(path)` — Addressables 异步加载面板

**Panel 生命周期：**
```
Closed → Open() → OnEnterAnimation (LitMotion fade/slide/scale)
  → Opening → Opened → (Pause/Resume) → OnExitAnimation
  → Closing → Closed
```

**Panel 类型：**
- `UIPanel`（基类）✅ Phase 1
- `UIDialog`（模态弹框，阻挡下层交互）✅ Phase 2
- `UIToast`（自动消失提示，可选时长 + 排队机制）✅ Phase 2
- `UIGuide`（教程覆盖层，步骤驱动）✅ Phase 2

## 十一、动画系统五层架构

### 11.1 分层概览

```
┌────────────────────────────────────────────────────────────────┐
│                    Unity Playable Graph                        │
│                         ▲                                      │
│  Layer 5: 运动层 (Motion Layer)                                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 物理计算 · 根运动集成 · 碰撞解决 · 地面吸附 · IK 求解     │  │
│  └──────────────────────────────────────────────────────────┘  │
│                         ▲                                      │
│  Layer 4: 行为层 (Behavior Layer)                               │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 动画处理 · 混合树评估 · 状态机转换 · 运动数据生成         │  │
│  └──────────────────────────────────────────────────────────┘  │
│                         ▲                                      │
│  Layer 3: 请求层 (Request Layer)                                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 请求过滤 · 优先级仲裁 · 双缓冲交换                         │  │
│  └──────────────────────────────────────────────────────────┘  │
│                         ▲                                      │
│  Layer 2: 决策层 (Decision Layer)                               │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 移动输入 · 战斗输入 · 上下文判断 · AnimationRequest 生成   │  │
│  └──────────────────────────────────────────────────────────┘  │
│                         ▲                                      │
│  Layer 1: 世界信息收集 (Knowledge Pool / Sensor)                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 玩家位置 · 敌人位置 · 地形 · 武器状态 · 速度 · 输入状态   │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────┘
```

### 11.2 数据流

```
KnowledgePool → DecisionLayer → AnimationRequest
  → RequestLayer (filter + prioritize) → BehaviorLayer (state machine + blend)
  → MotionLayer (physics + IK) → PlayableGraph → Unity Animator
```
