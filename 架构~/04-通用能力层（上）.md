## C1 — MemoryPack 序列化

- **状态**：✅ 已实现
- **命名空间（Core）**：`HN.Framework.Core.Capability.Serialization`
- **命名空间（Unity）**：`HN.Framework.Unity.Capability.Serialization`

**设计：**

```
Core 层：
  ISerializer 接口 — 统一的序列化/反序列化 API
  MemoryPackSerializer 包装器 — 底层 MemoryPack 引擎封装
  MemoryPackFormatterProvider — 自定义类型格式化器注册提供器
  FixedMathSharpFormatters — Fixed64, Vector2d/3d/4d, FixedQuaternion, Fixed4x4,
                              FixedBoundBox/Sphere 等
  FormattersInitializer — RegisterAll() 批量注册 Core 层格式化器

Unity 层：
  UnityFormatters — Vector3, Quaternion, Color, Matrix4x4 等 16 种格式化器
  UnityFormattersInitializer — RegisterAll() 批量注册，内部调用 Core 层的 FormattersInitializer
  FishNetSerializerAdapter — 将 MemoryPack 注入 FishNet 的序列化管道
```

**集成关系：**

| 使用方 | 说明 |
|--------|------|
| C6 Network | 网络消息二进制序列化 |
| C8 Storage | 存档文件二进制序列化 |
| L4 Sheet | 二进制配置表加载 |
| C2 Debug | 结构化日志导出（二进制格式） |

## C6 — 网络系统

- **状态**：✅ 已完成（含 C6.1 状态同步 + C6.2 预测与校验，C6.3 规划中）
- **命名空间（Core）**：`HN.Framework.Core.Capability.Network`
- **命名空间（Unity）**：`HN.Framework.Unity.Capability.Network`

**封装策略：最大程度复用 FishNet 核心原语，不重复造轮子。**

| FishNet 能力 | 策略 |
|-------------|:----:|
| 底层传输 / 连接管理 / 心跳 | ✅ 直接使用 |
| **NetworkBehaviour / NetworkObject** | ✅ **使用** — NetworkEntityView 的基类 |
| **SyncVar / SyncList / SyncDictionary** | ✅ **使用** — Entity 状态自动同步核心 |
| **RPC（ServerRpc / ObserversRpc / TargetRpc）** | ✅ **使用** — 客户端 ↔ 服务端通信 |
| **Spawn / Despawn** | ✅ **使用** — 网络实体生命周期管理 |
| **Interest Management** | ✅ **使用** — 按距离/对象控制同步范围 |
| **TimeManager** | ✅ **使用** — 网络时间同步 |
| **Custom Serializer** | ✅ **使用** — MemoryPack 注册为 FishNet 序列化器 |
| NetworkTransform / NetworkAnimator | ❌ 框架自行封装 |
| 带宽统计 / 调试工具 | ✅ 通过接口暴露 |

**架构定位：NetworkBehaviour 是 Model 与 View 之间的同步传输层，不替代 MVC 任何一层。**

```
┌─────────────────────────────────────────────────────┐
│  Core（客户端 & 服务端完全一致）                       │
│  Model  ← 数据 + 业务逻辑（Server 侧权威）             │
│  Controller ← 协调逻辑                                │
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────┴──────────────────────────────┐
│  Unity（同步传输层）                                  │
│  NetworkEntityView : NetworkBehaviour               │
│    ├── [SyncVar] 同步 Model 状态                     │
│    ├── ServerRpc    客户端 → 服务端操作请求            │
│    └── ObserversRpc 服务端 → 所有客户端广播            │
│                                                     │
│  #if !UNITY_SERVER                                  │
│    View  ← 从 synced Model 读取数据显示               │
└─────────────────────────────────────────────────────┘
```

**Core 层定义：**
```
INetworkManager 接口：
  bool IsServer / IsClient / IsHost
  StartServer() / StartClient() / StopConnection()
  event OnClientConnected / OnClientDisconnected

IFrameSyncManager 接口 — 帧同步管理器（继承 ITickable）
FrameInput — 帧输入数据结构
FrameInputBuffer — 固定容量环形缓冲区
IChecksumProvider — 可插拔校验和接口
LockstepManager — IFrameSyncManager 实现，固定帧率驱动器
SyncedModel<T> / SyncCollection<T> — 同步数据模型
```

**Unity 层实现：**
```
FishNetNetworkManager : NetworkBehaviour, INetworkManager
  └── 封装 FishNet.NetworkManager，注入 GameWorld

NetworkEntityView : NetworkBehaviour
  └── EntityView(V2) 的子类，挂载 NetworkObject
  └── SyncVar<T> 字段自动同步 Entity 状态到所有客户端
  └── RegisterSyncedModel / ApplySyncValue — 桥接 SyncVar 回调到 IReadOnlyModel
  └── ServerRpc / ObserversRpc 转发客户端输入 / 广播服务端状态

FishNetSyncedList<T> / FishNetSyncedDictionary<TKey,TValue> — 集合同步包装器
LockstepNetworkDriver — 纯 C# 网络驱动，通过 FishNetMessageBus 收发帧同步消息
```

### C6.1 状态同步机制

- **状态**：✅ 已实现

基于 FishNet SyncVar<T> + SyncList + SyncDictionary，不自建同步协议。

```
SyncVar<T> — 简单字段自动同步：
  NetworkEntityView 中声明 SyncVar<T> 字段
  → FishNet 仅同步变更字段（delta compression）
  → SyncVar<T>.OnChange 回调 → SyncedModel<T>.SetValue() → 驱动 View 更新

SyncList / SyncDictionary — 集合增量同步：
  FishNetSyncedList<ItemSlot> Inventory
  → 仅发送 add/remove/update 操作
  → 客户端通过 OnCollectionChanged 事件监听增量变更

SyncVar<T> → IReadOnlyModel 绑定：
  Model（Core）     ← 服务端权威计算
  NetworkEntityView  ← SyncVar<T> 同步到客户端
  SyncedModel<T>     ← 通过 ApplySyncValue 桥接
  IReadOnlyModel<T>  ← View 通过 PropertyBinder(V3) 监听
```

**核心类：**
- `SyncedModel<T>`（Core）— 可写数据容器，实现 IReadOnlyModel<T>，带脏标记追踪
- `SyncCollectionChange<T>` / `SyncDictChange<TKey,TValue>`（Core）— 集合/字典变更事件参数
- `FishNetSyncedList<T>`（Unity）— FishNet SyncList<T> 包装器
- `FishNetSyncedDictionary<TKey,TValue>`（Unity）— FishNet SyncDictionary 包装器

### C6.2 客户端预测与服务器校验

- **状态**：✅ 已实现

**使用 FishNet 内置 Prediction 系统，不自建。**

```
FishNet Prediction API：
  - PredictionManager：管理预测状态快照
  - Reconciliation：服务端矫正 → 客户端回滚 + 重放未确认操作
  - LagCompensation：服务端回溯到客户端过去时刻做 Hit 检测

框架封装层（HN.Framework.Unity.Capability.Network.Prediction）：
  PredictedNetworkEntityView（继承 NetworkEntityView）
    辅助方法模式：
    ├── CreateReplicateData<T>(tick)     — 从对象池获取输入
    ├── ReleaseReplicateData<T>(data)    — 归还到对象池
    ├── StoreReplicateInput(input)       — 存储到历史缓冲区
    ├── GetReconcileInputs(from, to)     — 检索历史输入用于重放
    ├── ApplyReconcileState<T>(data)     — 应用服务端权威状态
    └── GetNetworkTickInfo()             — 获取网络时序信息

  PredictionManagerAdapter — 封装 FishNet PredictionManager
  LagCompensationAdapter — 封装 FishNet RollbackManager + ColliderRollback

Core 层接口与数据模型：
  PredictionInputBase — 预测输入基类（MemoryPackable + IReference）
  PredictionReconcileData<T> — 调和数据泛型结构体
  IPredictedEntity — 预测实体接口
```
