## 三、三层架构全景

### 3.1 层级架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                      Level (关卡层)                               │
│                                                                 │
│  ┌─────────────────────────┐   ┌─────────────────────────────┐  │
│  │    ViewModule (视图层)    │◄─►│   LogicModule (逻辑层)       │  │
│  │   V1: UI 运行时           │   │   L1: MVC 框架              │  │
│  │   V2: ViewFactory+EntityView│   │   L2: HFSM 状态机              │  │
│  │   V3: PropertyBinder     │   │   L3: Entity 系统           │  │
│  │   V4: 动画 Playable 运行  │   │   L4: Sheet/Config 系统     │  │
│  │   V5: 音频播放组件        │   │   L5: 图数据模型             │  │
│  └─────────────────────────┘   │   L6: 动画数据模型           │  │
│                                 │   L7: 战斗数值体系           │  │
│                                 │   L8: 任务成就系统           │  │
│                                 │   L9: 物品背包装备           │  │
│                                 │   L10: AI 行为框架           │  │
│                                 └─────────────────────────────┘  │
│  L0: GameplayTag（Level 共享层，不归属于 Logic/View 子层）         │
└───────────────────────────┬─┬────────────────────────────────────┘
                            │ │  双向通信
┌───────────────────────────┼─┼────────────────────────────────────┐
│               CapabilityModule (通用能力层)                        │
│                            │ │                                    │
│  C1:MemoryPack  C2:Debug   C3:L10n     C4:Asset   C5:Log        │
│  C6:Network     C7:Event   C8:Storage  C9:Proc    C10:Pool      │
│  C11:Audio      C12:Cutscene  C13:UI   C14:Input  C15:Scripting │
│  C16:Physics    C17:Camera  C18:Security C19:Scene C20:TimeWx   │
│  C21:Performance                                                │
└───────────────────────────┬──────────────────────────────────────┘
                            │  单向依赖
┌───────────────────────────┼──────────────────────────────────────┐
│                   DriverLayer (驱动层)                             │
│                            ▼                                      │
│  D1: GameWorld    D2: 基础类库    D3: Debug 基础设施               │
│  D4: 平台抽象层（Unity 适配 / 渲染 / 时间 / 协程）                 │
└──────────────────────────────────────────────────────────────────┘
```

**依赖规则：**
- `Level` ↔ `CapabilityModule`：双向通信
- `CapabilityModule` → `DriverLayer`：单向依赖
- `DriverLayer`：自底向上，GameWorld 在最上层驱动所有模块

### 3.2 模块编号体系

| 层级 | 编号 | 子层 | 模块列表 |
|------|------|------|----------|
| Driver | D1 | 全局驱动根节点 | GameWorld |
| Driver | D2 | 基础类库 | ITickable, IReference, HNLogicTime, ReferencePool, MemoryPack Core, HNRandom, FixedMathSharp ⚠️(可选，Core/Vendor Lean + 剥离属性 + 自定义格式化器) |
| Driver | D3 | Debug 基础设施 | LogLevel, ILogChannel, LogEntry, IDebugHub, IDebugCommand |
| Driver | D4 | 平台抽象层 | GameWorldDriver, AssetOperator×3, Log/Time/Coroutine Providers, GameObjectPool, HNDictionary, HNRenderPipeline, GlobalSettings |
| Capability | C1-C21 | 通用能力 | 序列化、调试、本地化、资源、日志、网络、事件、存储、流程、对象池、音频、过场、UI、输入、脚本、物理、摄像机、安全、场景流送、时间天气、性能监控 |
| Level | L0 | 共享层 | GameplayTag（标签系统，不归属于 Logic/View） |
| Level.Logic | L1-L10 | 逻辑基础设施 | MVC、HFSM、Entity、Sheet、Graph、Animation、Combat、Quest、Inventory、AI |
| Level.View | V1-V5 | 视图基础设施 | UI 运行时、ViewFactory、PropertyBinder、动画 Playable、音频播放 |

## 四、程序集规划

### 4.1 程序集内容总览

#### HN.Framework.Core（`noEngineReferences: true`）

Core 层定义全部接口、纯 C# 逻辑和 Level.Logic 数据模型。

| 子层 | 编号 | 核心内容 |
|------|------|----------|
| Driver | D1-D3 | GameWorld, ITickable/IReference, HNLogicTime, ReferencePool + 17 PooledCollections, ObjectPool<T>/PoolBase, MemoryPack Core, HNRandom, FixedMathSharp(Lean vendored), Json/JsonObject, LogLevel/ILogChannel/LogEntry/IDebugHub/IDebugCommand, IEventBus |
| Capability | C1-C21 | 全部能力接口（详见通用能力层）+ 纯 C# 实现：ProcedureManager(C9), ObjectPoolManager(C10), EventBus(C7), DebugHub(C2), 各模块数据模型 |

| Level.Logic | L1-L10 | MVC(Controller/Model/IReadOnlyModel), HFSM, Entity, Sheet, Graph, Animation, Combat(GAS), Quest, Inventory, AI(BT+感知+寻路)


### 4.3 跨仓库程序集依赖规则

| 依赖方向 | 方式 | 说明 |
|----------|------|------|
| Scripts → Framework | asmdef `references` | 显式引用 Core 和 Unity 的 GUID |
| Art → Framework | Unity 资源引用 | Shader 引用 Framework 的 ShaderLibrary |
| Design → Scripts | Prefab 组件引用 | Prefab 上挂载的 MonoBehaviour 来自 Scripts 仓库 |
| Design → Art | Prefab 资源引用 | 引用的 Mesh/Material 来自 Art 仓库 |
| Framework → 上层 | **禁止** | asmdef 的 `references` 不包含任何上层仓库的 GUID |
| `Core` → FishNet | **禁止** | 纯 C# 层只定义 `INetworkManager` 接口 |
| `Unity` → FishNet | asmdef `references` | 唯一在 Framework 内引用 FishNet 的位置 |
