# 06 · 2D 骨骼动画子系统（Spine 类）

> 动画模块文档 · 上级索引：[README](./README.md) · 关联：[04 LOD](./04-视野剔除与LOD分级.md) · [08 Playable 限制](./08-Playable限制与模块对接.md)

## 一、定位

类似 Spine 的 2D cutout 骨骼动画：**只导入 + 渲染**（制作在 DCC），**不使用第三方 Spine 插件**。与 3D Playable 路径**并列**，共享逻辑层 + LOD + Jobs/Burst。导入格式**仅兼容 Spine JSON**。

## 二、特性范围（首版子集）

| 包含 | 暂不考虑 |
|------|----------|
| Bones / Slots / Attachments（Region / Mesh） | Constraints（IK / Transform / Path） |
| Skins（换装） | Deform 顶点形变 |
| Timelines：Rotate / Translate / Scale / Attachment / Color / DrawOrder / Event | Clipping / LinkedMesh / Mix-Blend |
| 动态 mesh skinning + DrawOrder | — |

## 三、逻辑 / 表现切分

| 部分 | 归属 |
|------|------|
| 播哪个 animation / 时间推进 / 事件 | 逻辑（复用 Layer1-4） |
| 骨骼求值 / skinning / 顶点层级 | 表现（Skeleton2D 子系统） |
| mesh 构建 / DrawOrder / 材质批次 | 表现渲染 |

## 四、数据模型（L6 扩展，Core）

命名空间 `...Logic.Animation.Skeleton2D`，MemoryPack 可序列化，走 Luban + AssetRef。核心类型：

| 类型 | 职责 |
|------|------|
| `SkeletonData` | 骨架根：Bones / Slots / Skins / Animations |
| `BoneData` | 骨骼：Name / ParentIndex / Length / Local TRS |
| `SlotData` | 槽位：Name / BoneIndex / AttachmentName / Color |
| `AttachmentData` | 附件：Type（Region / Mesh）+ Mesh 数据 |
| `MeshAttachment` | 蒙皮 mesh：Vertices / UVs / Triangles / Bones / Weights（≤4 骨/顶点） |
| `AnimationData` | 动画：Timeline 数组（Curve: Linear / Stepped / Bezier） |
| Timeline | Rotate / Translate / Scale / Attachment / Color / DrawOrder / Event |

## 五、导入结构（Spine JSON + Editor）

- Core 定义导入契约 `ISkeleton2DImporter`；Editor 解析 **Spine JSON** → `SkeletonData`
- 图集（atlas）切分 + `AssetRef<T>` 引用计数；换装走 Skin 映射 + 引用管理
- 转 MemoryPack `.bin` 运行时资源（对齐 L4/L6 现有管线）
- 校验：骨骼索引 / 附件引用 / 时间轴曲线合法性
- 曲线保真：对齐 Spine JSON 的 linear / stepped / bezier 逐帧插值

## 六、运行时求值 + 渲染（表现层）

```
SetAnimation(anim, loop) → 时间轴采样 + 曲线插值 → UpdateWorldTransform（骨骼层级）
  → Attachment 切换 → Skinning（顶点 ≤4 骨混合） → DrawOrder → 动态 Mesh → MeshRenderer
```

- 骨骼层级变换、skinning 可 `IJobParallelFor` + Burst
- **2D / 3D 统一批次管理**：按 材质 + 混合模式 合并 draw call

## 七、渲染方案（双支持，用户选择）

| 方案 | 说明 |
|------|------|
| CPU 动态 Mesh | 每帧构建 vertices/uvs/triangles（double-buffer 复用） |
| GPU Compute Skinning | 骨骼矩阵 → `ComputeBuffer` → compute/vertex shader |

- 由模块 Settings SO 开关选择
- 渲染管线无关：只输出 Mesh + 材质，Shader 由项目提供
- LOD：见 [04 · 2D Skeleton 的 LOD 降级](./04-视野剔除与LOD分级.md)

## 八、契约扩展

逻辑 → 表现的 2D 变体 `Skeleton2DState`：`AnimHash` / `NormalizedTime` / `Loop`。
