## 一、定位

**参数化程序化生成**姿态增量，叠加到基础姿态（非预烘焙动画）。四类：

| 子类 | 性质 | 驱动 |
|------|------|------|
| **呼吸** | 持续 | Perlin 噪声，速率随状态 |
| **后坐力** | 触发 + 衰减 | 脉冲（射击）→ 弹簧 |
| **受击抖动** | 触发 + 衰减 | 方向性脉冲（+ IK 联动） |
| **Turn-in-place** | 输入驱动 | 目标朝向突变 |

## 二、归属

| 部分 | 归属 |
|------|------|
| 触发 / 强度 / 方向（何时、多强） | **逻辑层**（gameplay） |
| 程序化 delta 生成 + 叠加 | **表现层** |
| Turn-in-place 的朝向决策 | 逻辑层；相位 + IK 合成 → 表现层 |

> 复用 **Additive 层（[12]）** 的叠加通道，delta 由**代码程序化生成**（非 additive clip）。

## 三、核心设计：程序化 Additive 源

**扩展 [12] Additive**，支持「程序化 delta 生成器」作为 additive 源：

```
AdditiveSource = clip 源  |  程序化源
程序化源：bone(s) + 通道 + 生成函数（正弦 / 脉冲 / 弹簧）+ 参数
```

- 产出 delta → 走既有 Additive 叠加与衰减
- 与 clip additive 混合共存

## 四、各子类设计

### 4.1 呼吸

- 驱动：**Perlin 噪声**（默认）→ 脊柱 / 胸廓 / 肩
- 参数：幅度、频率、相位偏移（错落感）
- 速率随状态：平静 / 疲劳 / 瞄准（逻辑层给参数）

### 4.2 后坐力（Recoil）

```
射击脉冲 → recoil profile（曲线 / 弹簧）→ 施加到手臂 / 躯干
  → 连射时脉冲**叠加累积** → 按恢复速度衰减
```

- 参数：后座力大小 / 方向 / 恢复速度 / 累积上限
- **身体后坐与相机后坐分离**

### 4.3 受击抖动（Flinch）

- 触发：受击方向 + 强度 → **方向性 delta**（沿受击方向反冲）
- 衰减：弹簧 / 振动
- **与 IK Rig 联动**（受击部位对齐）

### 4.4 Turn-in-place（原地转身）

```
目标朝向突变 → 角度差 Δ
  → 选转向动画（左/右 × 90°/180°）
  → FootIK（[20]）脚不移位（foot planting）
  → Sync（[13]）相位对齐
```

- 无位移转身，避免脚滑
- **选转向动画 + FootIK + Sync** 协同

| 技术 | 关系 |
|------|------|
| Additive（[12]） | 程序化源走 additive 通道（**扩展**） |
| IK Rig / FootIK（[16]/[20]） | Turn-in-place 脚部贴地 |
| Sync（[13]） | Turn-in-place 相位对齐 |
| 二次运动（[22]） | 弹簧 / 衰减模型复用 |
| Montage（[15]） | 动作可触发程序化叠加 |
| 逻辑层 | 触发 / 强度 / 方向注入 |
