## 核心数据契约

逻辑层产出契约，单向交给表现层消费：

| 类型 | 层 | 职责 |
|------|:--:|------|
| `AnimationWorldSnapshot` | 逻辑 | 世界信息纯数据（速度 / 输入 / 接地 / 标签），Unity 桥接每帧填入 |
| `AnimationRequest` | 逻辑 | 决策输出（状态哈希 / 优先级 / 来源：Locomotion·Combat·Hit·Interaction） |
| `AnimationLogicInstance` | 逻辑 | 每 Entity 一个逻辑实例（ITickable），Tick 驱动 Layer1→5，输出快照 + 运动意图 |
| `AnimationStateSnapshot` | 逻辑→表现 | 主导状态 / 归一化时间 / 播放速度 / 混合参数 / 层列表(clip+weight+mask) / 帧事件 / 版本号 |
| `MotionIntent` | 逻辑→移动 | 位移意图：根位移 delta + 朝向 delta |
| `AnimationRepresentation` | 表现 | 消费快照（ApplySnapshot）+ 设档（SetLod） |
| `AnimationLodLevel` | 表现 | 枚举 Full / Reduced / Simplified / Culled |

**表现层 Jobs 输入契约（blittable）**：逻辑层姿态数据打包为 blittable SoA（Core 内 `unsafe fixed` 内联数组，布局与 Unity.Mathematics 兼容，需 `allowUnsafeCode`），供表现层 memcpy 进 `NativeArray` 交给 Burst Job。字段：`AgentCount` / `NormalizedTime` / `LayerWeight` / `DominantState`。

> 逻辑层**只产出**该 blittable 契约（主线程计算），**不用 Job 执行**；Jobs 在表现层侧消耗它。

## 契约扩展（子模块）

各 feature 按需扩展契约，均在 `AnimationStateSnapshot` 或并行结构上增量添加：

| feature | 扩展 | 详见 |
|---------|------|------|
| Inertialization | `TransitionPolicy`（None / CrossFade / Inertialization）+ `TransitionDuration` | [07](./07-Inertialization惯性化过渡.md) |
| Additive 动画层 | `AdditiveLayers[]`（ClipHash / Weight / MaskId） | [12](./12-Additive动画层.md) |
| Sync Groups / Phase Matching | 复用现有 `NormalizedTime`（相位归逻辑层，无新字段） | [13](./13-SyncGroups相位匹配.md) |
| Motion Warping | 复用 `MotionIntent`（调整位移/朝向，无新字段） | [14](./14-MotionWarping位移匹配.md) |
| Montage / 一次性动作层 | `MontageLayers[]`（MontageHash / NormalizedTime / Weight / SlotType / MaskId） | [15](./15-Montage动作层.md) |
| IK Rig | Goals 注入（`IIKGoalProvider`，逻辑层 → 表现层） | [16](./16-IKRig骨骼操控.md) |
| 2D Skeleton | `Skeleton2DState`（AnimHash / NormalizedTime / Loop） | [06](./06-2D骨骼动画子系统.md) |
