---

## 一、定位

**全身多链协同 IK**：脚 + 手 + 骨盆 + 脊柱**同时约束**，带关节限制与优先级。

| 维度 | 单链 Solver（[20]） | **BodyIK** |
|------|:-------------------:|:----------:|
| 链数 | 1 | **多链协同** |
| 约束 | 单目标 | 目标 + 关节限制 + 距离/角度 |
| 求解 | 直接解算 | **迭代约束求解** |
| 用途 | 脚贴地 / 瞄准 / 抓取 | 复杂姿态（爬梯 / 驾驶 / 倒地 / 骑乘） |

## 二、归属

- **表现层 P3**（IK Rig 求解层）
- 数据（L6）：多链 + 目标 + 约束 + 优先级

## 三、系统组成

```
BodyIK
  ├── 链集合（脚 / 手 / 骨盆 / 脊柱）
  ├── 目标（位置 / 旋转）
  ├── 约束（距离 / 角度 / 关节限制）
  └── 优先级 / 权重
```

## 四、算法

| 方案 | 说明 |
|------|------|
| **XPBD（采用）** | 位置基，多约束统一、稳定、易并行 |
| 约束投影 | 逐约束迭代投影 |
| 优化求解 | 最小化目标误差 + 约束惩罚 |

- 目标误差最小化 + 约束满足，**迭代收敛**
- **迭代次数可配**（默认 **12**，范围 8~16）
- Job / Burst 并行

## 五、与 IK Rig / Control Rig 关系

- 作为 IK Rig 的**多链 Solver**（扩展 [16]）
- **复用单链 Solver**（ChainIK / FABRIK / TwoBone，[16]/[20]）作为基础单元
- 可作为 Control Rig（[21]）节点图内的求解节点

## 六、约束类型（全）

| 约束 | 说明 |
|------|------|
| 位置 | 脚 / 手贴目标 |
| 旋转 | 对齐朝向 |
| 距离 | 保持骨长 |
| 角度 | 关节角度限制 |
| 关节限制 | 各轴范围（避免超自然） |

## 七、与现有技术协作

| 技术 | 关系 |
|------|------|
| 单链 Solver（[16]/[20]） | BodyIK 的基础单元 |
| Control Rig（[21]） | 可调用 BodyIK 节点 |
| Dynamic Bone（[22]） | 在 IK **之后** |
| PSD / DQ（P6/P7） | 蒙皮侧 |
| LOD（[04]） | 重 → **L0 only** |

## 八、LOD

| 档 | BodyIK |
|:--:|--------|
| L0 | 全（可配迭代次数） |
| L1 / L2 / L3 | **关**（计算重） |
